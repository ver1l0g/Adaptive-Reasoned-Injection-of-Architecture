script that generates them (all reproducible: run the prep script to
regenerate the CSVs).

## Support folders

- `harness/` — run_*.py benchmark drivers, monitor_*.ps1 chains, launchers.
  All write results incrementally (crash-safe tee'd logs).
- `results/` — results CSVs + report txt files (feynman card, multiseed,
  queue reports).
- `archives/` — old logs, one-off scratch, dataset tarballs.
- `checkpoints/` — periodic graph snapshots (checkpoints/<task>/graph.json).
- `tests/` — C++ unit tests (12, in tests/main_tests.cpp).
- `subgraph_library.txt` — cross-run behavioral library (795 entries).
- `RUN_QUEUE.bat` — the self-contained overnight queue (see
  README_OVERNIGHT.txt).

## Conventions

- Suite CSVs are generated by the suite folder's prep script (never edit
  by hand; rerun the script).
- Run harnesses from problems/: `python harness/run_feynman.py ../aria9.exe 100`
- Result CSVs land in results/; the harness paths already point there.
